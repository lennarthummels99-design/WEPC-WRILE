# Party Position Change Across Electoral Systems

Replication materials for the bachelor thesis:

"Are Major Political Parties in Majoritarian Electoral Systems
More Inclined to Change Party Position Compared to Parties
in Proportional Electoral Systems?"

## Author

Lennart Hummels

## Data

The analysis uses data from the Manifesto Project (MARPOR) and the Democratic Electoral Systems (DES).

MARPOR: https://manifesto-project.wzb.eu/ (MPDS2025a)
DES: https://mattgolder.com/elections (Version 5.0)
